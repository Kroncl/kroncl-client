# Публичные компании

Компании на платформе Kroncl могут быть двух типов:

- <span className={mdx.underline}>приватная</span> — не участники не имеют доступа к просмотру реквизитов компании;
- <span className={mdx.underline}>публичная</span> — не участники имеют доступ к просмотру реквизитов компании.

Метод получения реквизитов публичной компании:
