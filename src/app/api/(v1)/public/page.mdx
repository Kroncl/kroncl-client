# Публичные методы

Публичные методы API — методы, не требующие <span className={mdx.codeTag}>Bearer &lt;API-KEY&gt;</span> в заголовке <span className={mdx.codeTag}>Authorization</span>, то есть доступные без авторизации всем пользователям.

В числе таких методов:

- Health-Check — метод проверки работоспособности платформы;
- получение статуса платформы: инциденты по компонентам;
- статус биллинга платформы;
- получение тарифных планов;
- все существующие в организации разрешения;
- получение карты публичной компании.
