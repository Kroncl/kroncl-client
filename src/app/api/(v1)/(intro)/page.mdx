## Создание клиента

Создаёт нового клиента в базе организации.

### Запрос


<MDXMermaBlock
    title="Архитектура API"
    chart={`
graph TD
    A[Client] -->|API Key| B[Auth Middleware]
    B -->|JWT| C[Account Context]
    C --> D[Companies]
    D --> E[Modules]
    E --> F[FM]
    E --> G[CRM]
    E --> H[HRM]
`}
/>

<MDXCodeBlock
    language="bash"
    code={`curl -X POST https://kroncl.com/api/companies/org123/modules/crm/clients \\
  -H "Authorization: Bearer krn_abc123def456..." \\
  -H "Content-Type: application/json" \\
  -d '{
    "first_name": "Иван",
    "type": "individual",
    "source_id": "src-456"
  }'`}
/>
