# Стандарты

API Kroncl во всех своих методах соблюдает определённые стандарты, включая <span className={mdx.underline}>единый формат ответов</span>, <span className={mdx.underline}>пагинацию</span> и <span className={mdx.underline}>формат временных меток</span>. Соблюдение этих стандартов является главной причиной, по которой разработчик, вызывающий тот или иной метод, может быть уверен в том, что API вернёт данные в определённом формате. Это, в свою очередь, даёт возможность корректно обрабатывать все ответы, избегая неожиданных проблем с форматами.

# Ответы методов

Для ответов большинства методов (за исключением методов, возвращающих бинарные данные) используется кодировка <span className={mdx.codeTag}>application/json</span>. <span className={mdx.codeTag}>HTTP</span>-статусы соответствуют классической методологии <span className={mdx.codeTag}>REST</span>: <span className={mdx.codeTag}>2xx</span>, <span className={mdx.codeTag}>4xx</span>, <span className={mdx.codeTag}>5xx</span>.

Методы этого API возвращают данные в <span className={mdx.underline}>едином формате ответов</span>, структура которого одинакова как в случае ошибок, так и в случае успеха.
