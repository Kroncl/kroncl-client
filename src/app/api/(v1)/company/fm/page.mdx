# Финансы

Модуль <span className={mdx.codeTag}>FM</span> — управление финансами, транзакциями, категориями, аналитикой, контрагентами, кредитами и прогнозированием.

## Возможности

- создание и управление финансовыми транзакциями (доходы/расходы);
- сторнирование транзакций без удаления данных;
- управление категориями транзакций;
- сводная аналитика и группировка по категориям, сотрудникам и периодам;
- управление кредитами и долгами, отслеживание платежей (в разработке);
- прогнозирование финансов с помощью модели Theta;
- генерация Excel-отчётов по финансовому модулю.
