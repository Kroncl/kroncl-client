# Прогнозирование

Методы для прогнозирования финансов организации на основе исторических данных. Используется математическая модель <span className={mdx.codeTag}>Theta</span>, работающая от 2 точек анализа и не требующая настройки.

<h1 id='timeline'># График прогноза</h1>
<MDXMethodBlock path='/companies/{id}/modules/fm/forecast/timeline' method='GET' />

Возвращает массив точек для построения графика прогноза баланса. Исторические точки помечены <span className={mdx.codeTag}>is_actual: true</span>, прогнозные — <span className={mdx.codeTag}>is_actual: false</span>.

<h1 id='summary'># Сводка прогноза</h1>
<MDXMethodBlock path='/companies/{id}/modules/fm/forecast/summary' method='GET' />
