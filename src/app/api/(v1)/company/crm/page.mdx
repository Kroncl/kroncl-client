# Клиенты (CRM)

Модуль <span className={mdx.codeTag}>CRM</span> — управление клиентской базой, источниками, аналитикой и отчётами.

## Возможности

- создание и управление клиентами (физлица и юрлица);
- ведение источников привлечения клиентов;
- активация и деактивация клиентов и источников;
- сводная аналитика по клиентской базе;
- группировка клиентов по источникам и периодам;
- генерация Excel-отчётов по клиентам и источникам.
