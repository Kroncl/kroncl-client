# Управление персоналом

Модуль <span className={mdx.codeTag}>HRM</span> — управление сотрудниками, должностями и анализ штата.

## Возможности

- создание карточек сотрудников с контактными данными;
- привязка аккаунтов платформы Kroncl к карточкам сотрудников;
- назначение сотрудников на должности с наследованием разрешений;
- активация и деактивация сотрудников без удаления данных;
- создание должностей с гибким набором разрешений;
- обновление и удаление должностей;
- сводная аналитика по штату: количество, статусы, новые сотрудники;
- группировка статистики по дням, месяцам и годам;
- генерация Excel-отчётов по сотрудникам и должностям.
