# Тарификация компании

Методы для управления тарифным планом организации.

<h1 id='current'># Получение текущего плана</h1>
<MDXMethodBlock path='/companies/{id}/pricing' method='GET' />

Возвращает текущий тарифный план организации и оставшееся время.

## Структура ответа

<MDXJsonSchemaBlock title='RESPONSE_DATA' fields={companyPricingPlanFields} />

## Тариф

<MDXJsonSchemaBlock title='PRICING_PLAN' fields={pricingPlanFields} />

## Примеры ответов

<MDXStatusesBlock codes={currentPlanResponseCodes} />

<h1 id='migrate'># Смена тарифа</h1>
<MDXMethodBlock path='/companies/{id}/pricing/migrate' method='POST' />

## Структура запроса

<MDXJsonSchemaBlock title='MIGRATE_REQUEST' fields={migratePlanRequestFields} />

## Структура ответа

<MDXJsonSchemaBlock title='PRICING_TRANSACTION' fields={pricingTransactionFields} />

## Примеры ответов

<MDXStatusesBlock codes={migratePlanResponseCodes} />
