# Базовые действия

Базовые методы для управления организацией.

<h1 id='get'># Получение компании</h1>
<MDXMethodBlock path='/companies/{id}' method='GET' />

Возвращает данные организации. Аккаунт должен быть участником.

## Структура ответа

<MDXJsonSchemaBlock title='COMPANY' fields={companyDetailFields} />

## Примеры ответов

<MDXStatusesBlock codes={getCompanyResponseCodes} />

<h1 id='update'># Обновление</h1>
<MDXMethodBlock path='/companies/{id}' method='PATCH' />

Обновляет данные организации. Все поля опциональны.

## Структура запроса

<MDXJsonSchemaBlock title='UPDATE_REQUEST' fields={updateCompanyRequestFields} />

## Структура ответа

<MDXJsonSchemaBlock title='COMPANY' fields={companyDetailFields} />

## Примеры ответов

<MDXStatusesBlock codes={updateCompanyResponseCodes} />

<h1 id='permissions'># Разрешения компании</h1>

## Структура ответа

<MDXJsonSchemaBlock title='PERMISSION' fields={companyPermissionsFields} />

<MDXStatusesBlock codes={permissionsResponseCodes} />
