# Документы компании

<span className={mdx.underline}>Документы компании</span> — все сгенерированные модулями файлы: отчёты, накладные и прочее. Для получения бинарных файлов используйте метод <Link href='/api/company/storage/media#get-file' className={mdx.link}>объектного хранилища</Link>.

<h1 id='list'># Получение документов</h1>
<MDXMethodBlock path='/companies/{id}/modules/docs' method='GET' />

Возвращает список сгенерированных документов с пагинацией и фильтрацией по модулю и типу.
