# 1. Хранилище компании

В этой документации уже проводилась аналогия организации с изолированным контейнером, 
хранящим данные компании. Мы разделяем два типа хранилищ компании внутри такого контейнера:
 
- <span className={styles.underline}>хранилище данных (база данных)</span>: отвечает за хранение текстовых данных модулей;
- <span className={styles.underline}>хранилище файлов (объектное)</span>: отвечает за хранение документов, изображений и других файлов компании.
<br />

Каждый тип хранилища в рамках организации имеет свои лимиты, зависящие от выбранного <Link className={styles.link} href='/docs/companies/pricing'>тарифного плана</Link>.

Контур из этих двух подсистем хранения носит обобщённое название <span className={styles.underline}>«Хранилище»</span>.
Информация о хранилище находится в одноимённом разделе (левая боковая панель пространства организации).

<MDXImageBlock src='/images/docs/company-storage.png' label='Просмотр ресурсов хранилищ.' />

Подробнее о каждом типе хранилища читайте в дочерних главах этого раздела.

# 2. Виджеты хранилища

Сводка об использовании хранилищ организации доступна в <Link href='/docs/companies/summary' className={styles.link}>сводке</Link> и на боковой панели в виде <span className={styles.underline}>полос-индикаторов</span>, заполняющихся
по мере приближения к лимитам хранилища текущего тарифного плана. Если вы видите, что один из индикаторов практически заполнен акцентным цветом, рекомендуем ознакомиться с подглавами документации этого раздела.
