# 1. Хранилище файлов организации

<span className={styles.underline}>Хранилище файлов организации / Объектное хранилище</span> используется для хранения медиа-данных компании, включая всевозможные отчёты, документы, накладные и прочие данные, представленные в виде файлов.

Файловое хранилище компании имеет лимиты, зависящие от тарифного плана:

- количество файлов (единицы)
- объём файлов (мегабайты)
<br />
При достижении лимитов учётная система перейдёт в <span className={styles.underline}>режим чтения</span>, запрещающий создание, обновление или удаление объектов в учётной системе.
Информация об использовании хранилища файлов организации доступна в разделе <span className={styles.underline}>«Хранилище»</span> пространства организации.

Мы предоставляем возможность в любой момент получить актуальную информацию об использовании хранилища файлов компании, включая:

- текущее количество файлов
- текущий объём файлов
- процентное отношение использованных лимитов файлового хранилища (полосы-индикаторы)

# 2. Достижение лимитов

Если вы видите, что лимиты файлового хранилища текущего тарифного плана достигнуты (или практически достигнуты), рекомендуем повысить уровень тарифного плана или
обратиться в службу поддержки за повышением лимитов.
