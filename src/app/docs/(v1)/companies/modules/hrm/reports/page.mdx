# 1. Отчёты


Модуль «Управление персоналом» предоставляет функции генерации отчётов. 
Для просмотра уже созданных файлов перейдите на вкладку <span className={styles.underline}>«Отчёты»</span> модуля управления персоналом.


<MDXImageBlock src='/images/docs/company-hrm-docs.png' label='Просмотр отчётов.' />


<MDXInfoBlock type='info' title='Формат отчётов'>
    Для генерации отчётов используется формат <span className={styles.tag}>.xlsx</span> — Microsoft Excel. Для каждого типа данных используется отдельный лист.
    Некоторые ячейки могут иметь комментарии.
</MDXInfoBlock>
<MDXInfoBlock type='warning' title='Лимит строк'>
    Каждый отчёт имеет ограничение в <span className={styles.tag}>10000</span> строк на одном листе. При необходимости увеличения лимита обратитесь в техническую поддержку.
</MDXInfoBlock>


# 2. Создание отчёта


Для создания нового отчёта нажмите соответствующую кнопку на странице просмотра отчётов.


При создании отчёта необходимо выбрать как минимум один тип данных, используемый в отчёте. Выберите несколько типов для <span className={styles.underline}>композитного отчёта</span>.


Таким образом, доступны:


- сотрудники: в отчёт попадёт информация о всех сотрудниках, включая контактную информацию;
- должности: в отчёт попадёт информация о всех должностях.
<br />
После завершения генерации (обычно до 10 секунд) вам станет доступен файл созданного отчёта.
