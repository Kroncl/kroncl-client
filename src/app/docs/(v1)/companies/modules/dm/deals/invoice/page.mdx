# 1. Накладная сделки

Модуль <Link href='/docs/companies/modules/dm' className={styles.link}>«Управление сделками»</Link> предоставляет функции генерации накладных к сделкам в формате <span className={styles.underline}>PDF</span>. 

Для создания новой накладной перейдите на вкладку <span className={styles.underline}>«Накладная»</span> целевой сделки.

<MDXImageBlock src='/images/docs/dm-deal-create-invoice.png' label='Создание накладной.' />

# 2. Состав накладной

Состав накладной состоит из позиций, каждая из которых определяется:

- <span className={styles.underline}>наименованием</span>;
- <span className={styles.underline}>количеством единиц</span>;
- <span className={styles.underline}>ценой за единицу</span>;
<br />
Из <Link href='/docs/companies/modules/dm/deals/order-structure' className={styles.link}>состава сделки</Link>, при наличии в нём товарных позиций, автоматически подгрузится состав заказа. Каждую товарную позицию можно удалять, изменять поля и менять порядок позиций в накладной.

# 3. Дополнительные параметры

При создании накладной предоставляется возможность изменения ряда параметров.

<MDXImageBlock src='/images/docs/dm-deal-invoice-fields.png' label='Параметры накладной.' />

# 3.1 Идентификатор накладной

По умолчанию накладная получит уникальный идентификатор, состоящий из 5 первых символов идентификатора сделки. Это значение можно менять.

# 3.2 Реквизиты компании

При создании накладной даётся возможность указать реквизиты компании, включая:

- <span className={styles.underline}>полное наименование</span>;
- <span className={styles.underline}>ИНН</span>;
- <span className={styles.underline}>ОГРН/ОГРНИП</span>;
- <span className={styles.underline}>банк-регистратор</span>;
<br />
По умолчанию реквизиты заполняются автоматически из <Link className={styles.link} href='/docs/companies/documents'>«Настроек документов»</Link>. Эти данные можно менять.

# 3.3 Условия гарантии

Это поле накладной также автоматически заполняется на основании настроек документов организации. Условия гарантии можно не заполнять - это не обязательное поле.

# 4. Результат генерации

Генерация накладной - ресурсоёмкий процесс, занимающий не более 2 минут ожидания (в большинстве случаев менее 30 секунд). Результатом является PDF-документ, скачивание которого начнётся сразу после успешной генерации.
