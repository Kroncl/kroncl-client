# 1. Прогнозирование финансов

Модуль <Link href='/docs/companies/modules/fm' className={styles.link}>«Финансы»</Link> предоставляет функционал для 
прогнозирования динамики трат и доходов за целевой промежуток времени. Прогнозирование в Kroncl реализуется с применением математической модели <span className={styles.underline}>«Theta»</span> и в первую очередь является инструментом для владельцев организации.

<span className={styles.underline}>Важно</span>: подсистема прогнозирования доступна не во всех тарифных планах - проверяйте информацию при выборе тарифного плана.

# 3. Настройки прогнозирования

На странице прогнозирования даётся опция выбрать параметры прогнозирования, в том числе:

- <span className={styles.underline}>начальная дата анализа</span> - операции, созданные после даты, используются при анализе (по умолчанию - первая операция);
- <span className={styles.underline}>конечная дата анализа</span> - операции, созданные до даты, используются при анализе (по умолчанию - последняя операция);
- <span className={styles.underline}>горизонт прогнозирования</span> - количество дней, на которые система создаст прогноз.
<br />
После изменения настроек прогнозирования примените изменения, нажав на соответствующую кнопку.

# 4. Счётчики и график

Результатом прогноза являются просчитанные моделью показатели баланса к концу периода прогнозирования (горизонт) и график изменения баланса организации.

<MDXImageBlock src='/images/docs/fm-forecast-chart.png' label='Результат прогнозирования.' />

# 4.1 Счётчики

В числе прогнозируемых счётчиков:

- <span className={styles.underline}>баланс</span> к концу периода прогнозирования;
- <span className={styles.underline}>чистый поток</span> за период прогнозирования - разница между доходами и расходами за период прогнозирования. Положительное значение означает превышение доходов над расходами;
- <span className={styles.underline}>доходы</span>;
- <span className={styles.underline}>расходы</span>;
- <span className={styles.underline}>количество операций</span>.
<br />
# 4.2 График

График прогнозирования разделён на две части вертикальной линией:

- <span className={styles.underline}>непрерывная линия</span> - фактический баланс организации (уже существующие операции);
- <span className={styles.underline}>пунктирная линия</span> - прогноз изменения баланса организации.
<br />
# 5. Точность прогнозирования

Точность прогнозирования финансов <span className={styles.underline}>напрямую зависит</span> от количества дней периода анализа, в течение которых заносились траты и доходы организации. 
Минимальное количество дней анализа = <span className={styles.underline}>2 дня (2 точки)</span>. 

Не рекомендуем устанавливать горизонт прогнозирования, превышающий количество дней анализа более чем в 2 раза. Например: если вы внесли данные за 7 дней, горизонт прогноза лучше ограничить 14 днями.

Система отображает уровень уверенности в прогнозе: низкий (менее 30 дней истории), средний (30–89 дней), высокий (90 дней и более).

Математическая модель <span className={styles.underline}>Theta</span> не учитывает сезонность при составлении прогноза. Главная задача - выявить тренд и экстраполировать его на горизонт прогнозирования. Чем больше дней вносились данные о тратах и доходах организации, тем точнее получится прогноз.
