# 1. Отчёты


Модуль «Финансы» предоставляет функции генерации отчётов. 
Для просмотра уже созданных файлов перейдите на вкладку <span className={styles.underline}>«Отчёты»</span> модуля финансов.


<MDXImageBlock src='/images/docs/company-fm-docs.png' label='Просмотр отчётов.' />


<MDXInfoBlock type='info' title='Формат отчётов'>
    Для генерации отчётов используется формат <span className={styles.tag}>.xlsx</span> — Microsoft Excel. Для каждого типа данных используется отдельный лист.
    Некоторые ячейки могут содержать комментарии.
</MDXInfoBlock>
<MDXInfoBlock type='warning' title='Лимит строк'>

</MDXInfoBlock>


# 2. Создание отчёта


Для создания нового отчёта нажмите соответствующую кнопку на странице просмотра отчётов.


При создании отчёта необходимо выбрать как минимум один тип данных, используемый в отчёте. Выберите несколько типов для <span className={styles.underline}>композитного отчёта</span>.


Таким образом, доступны:


- транзакции (операции): в отчёт попадёт информация о всех финансовых операциях за промежуток времени (доступен ручной выбор периода);
- категории: в отчёт попадёт информация о категориях трат/доходов;
- долговые контрагенты: список контрагентов с их контактными данными;
- кредиты и займы: информация о кредитах, займах и графиках платежей.
<br />
После завершения генерации (обычно до 10 секунд) вам станет доступен файл созданного отчёта.
